# Changelog

All notable changes to the Student Management System (SMS) are documented
in this file.

The format follows Keep a Changelog principles, and the project adheres
to Semantic Versioning.

## [1.0.0] – Initial Governed Release

### Added
- Stable CLI v1 contract
- Deterministic exit code semantics
- Explicit version exposure via `sms --version`
- Formal versioning and compatibility guarantees

### Architectural Notes
- Repository-driven architecture is considered stable
- Application-level validation taxonomy is frozen
- Domain entities do not cross application boundaries

This release establishes the baseline contract against which all future
changes will be evaluated.
